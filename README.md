# Scientific Computing, Data Engineering & Machine Learning

A self-directed, mastery-based curriculum focused on scientific programming, numerical methods, data engineering, applied mathematics, statistics, and machine learning.

## Objectives

- Develop stronger scientific Python and numerical computing skills.
- Apply mathematical and statistical reasoning to real observational data.
- Build reproducible data ingestion, analysis, and machine learning workflows.
- Practice independent implementation, testing, profiling, and experimentation.
- Complete a scientific investigation using environmental observations.

## Curriculum

The curriculum follows six phases:

1. Scientific Python Foundations
2. Scientific Data Engineering
3. Mathematical & Statistical Foundations
4. Machine Learning & Experimentation
5. Scientific Software & Systems
6. Integrated Scientific Capstone

See [SYLLABUS.md](SYLLABUS.md) for the complete curriculum and [PROGRESS.md](PROGRESS.md) for learning progress.

## Development

Primary environment: Fedora Linux, Python, Git, and VS Code.

Dependencies and execution instructions will be added as the curriculum progresses.
